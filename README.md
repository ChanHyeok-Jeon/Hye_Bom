# Hye_Bom (혀 봄) · 혀 사진으로 보는 데일리 건강 체크

> 혀 사진을 찍어 등록하면 이미지를 업스케일링하고, YOLOv8로 혀 상태(설태·설색)를 분류한 뒤, **LLM이 건강 상태와 병원 방문이 필요한지, 약국 일반의약품 정도면 되는지**를 안내하는 AI 서비스

| | |
|---|---|
| **대회** | KISTI 바이오헬스 DATA·AI Level-UP 챌린지 |
| **기간** | 2025.08.04 ~ 2025.08.07 (기획·개발·발표를 하루 만에 진행) |
| **인원** | 3인 |
| **내 역할** | 기획·PM: 주제 선정, 서비스 흐름 설계, 작업 분배, 발표 |
| **결과** | 🏆 **최우수상 (KISTI 원장상)**, 2025.08.07 |

<br>

## 문제

혀의 색과 설태는 몸 상태를 가늠하는 단서지만, 일반인이 사진만 보고 판단하기는 어렵습니다.
휴대폰으로 찍은 혀 사진은 해상도와 조명이 제각각이라, 모델이 그대로 분류하기에도 품질이 부족했습니다.

## 해결

```
[혀 사진 촬영·등록]
      ↓
[업스케일링]  Real-ESRGAN x4 (서버) / Bicubic x2 (데모)
      ↓
[YOLOv8 분류]  KISTI 슈퍼컴퓨터 누리온에서 학습한 가중치
      ↓
[LLM 안내]  건강 상태 · 병원 방문 필요 여부 · 일반의약품 안내
```

- **분류 클래스 7종**: 담홍설, 홍설, 담백설, 열문설, 박태, 후태, 황태
- 로컬 데모(`demo/`)는 API 키가 없거나 LLM 호출이 실패해도 준비해 둔 안내문으로 대체되도록 만들었습니다.

<br>

## 저장소 구성

```
Hye_Bom/
├─ backend_fastapi/        # 대회용 API 서버
│   ├─ main.py             # FastAPI 진입점 (/analysis, /users)
│   ├─ routers/analysis.py # 업로드 → Real-ESRGAN x4 → YOLOv8 → 결과 이미지 반환
│   └─ utils/yolov8_utils.py
└─ demo/                   # 대회 후 로컬에서 바로 돌려 볼 수 있게 정리한 단일 파일 데모
    ├─ app_web.py          # 업로드 → 업스케일 → YOLOv8(best.pt) → 상태 안내까지 한 화면에 표시
    └─ best.pt             # 혀 상태 분류 가중치
```

## 실행 (데모)

```bash
cd demo
pip install fastapi uvicorn python-multipart ultralytics opencv-python openai
uvicorn app_web:app --port 8000
# 실제 LLM 요약을 쓰려면: export OPENROUTER_API_KEY=...
```

> ⚠️ 이 서비스는 대회용 시연이며 의료 진단을 대신하지 않습니다.
